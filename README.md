# Лига 5×5 Актобе — сайт (сезон 2026)

Проект на **Next.js 14 (App Router) + TypeScript + Tailwind CSS + Prisma + Supabase**. Полноценный сайт лиги (RU/KZ) + защищённая админ-панель для одного администратора. Турнирная таблица и статистика игроков не хранятся в базе отдельно — они всегда пересчитываются "на лету" из результатов матчей и событий (голы/карточки), поэтому всегда актуальны.

## ⚠️ Важно: как запустить

В облачной песочнице, где собирался этот проект, **нет доступа к npm-реестру и к интернету в целом** (сетевые ограничения окружения — заблокированы даже supabase.com, registry.npmjs.org и т.д.). Поэтому здесь нельзя было выполнить ни `npm install`, ни `prisma generate`, ни тем более подключиться к настоящей базе Supabase — даже если бы у меня были готовые ключи доступа, из этой песочницы до них физически нет сети. Весь код написан и вручную проверен статическим TypeScript-компилятором на синтаксические и явные ошибки (по всем ~100 файлам проекта — ошибок нет), но живого запуска `npm run dev` и проверки в браузере ни разу не было. Первый реальный запуск обязательно нужно сделать у вас — см. шаги ниже, это единственное, что дальше требует именно вас.

### 1. Установка

```bash
cd liga5x5-aktobe
npm install
```

`npm install` автоматически выполнит `prisma generate` (см. `postinstall` в package.json).

### 2. Создайте бесплатный проект Supabase

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте новый проект (бесплатный тариф Free — его достаточно для старта лиги).
2. **Project Settings → Database → Connection string**: скопируйте строку "Transaction pooler" (порт 6543) и "Session/Direct" (порт 5432).
3. **Project Settings → API**: скопируйте `Project URL` и `anon public` ключ.
4. Скопируйте `.env.example` в `.env.local` и заполните все 4 переменные:

```bash
cp .env.example .env.local
```

### 3. Примените схему базы данных и сид

```bash
npm run db:migrate     # создаст все таблицы по prisma/schema.prisma
npm run db:seed        # создаст сезон 2026 и текст регламента по умолчанию
```

### 4. Создайте аккаунт администратора

В панели Supabase: **Authentication → Users → Add user** — укажите свой email и пароль. Публичной регистрации на сайте нет: единственный созданный так пользователь и есть администратор.

### 5. Запуск

```bash
npm run dev
```

Откройте `http://localhost:3000` (перенаправит на `/ru`) и `http://localhost:3000/admin/login` для входа в админку.

Если при первом запуске появятся мелкие ошибки — это нормально для кода, ни разу не собиравшегося; пришлите мне текст ошибки, я поправлю за пару минут.

## Структура

```
prisma/
  schema.prisma          ← вся модель данных (Season, Team, Player, Match, Goal, Card, Regulation…)
  seed.ts                 ← создаёт сезон 2026 и регламент по умолчанию при первом запуске
src/
  app/[locale]/            ← публичный сайт, locale = "ru" | "kk"
    matches/ [matchId]/     ← список матчей и полная страница матча
    teams/ [teamSlug]/       ← список команд и карточка команды
    players/ [playerSlug]/    ← список игроков и карточка игрока
    standings/ stats/          ← турнирная таблица и статистика — авторасчёт
    news/ [newsSlug]/           ← новости
    videos/ rules/ about/        ← видео, регламент, о лиге + партнёры
    archive/ [season]/            ← архив сезонов (таблица + бомбардиры прошлых сезонов)
    join/                          ← заявка команды (пишет в БД)
  app/admin/
    layout.tsx              ← корневой layout админки (не зависит от локали)
    login/page.tsx           ← вход
    (dashboard)/             ← всё, что видно после входа (не влияет на URL)
      teams/ players/ matches/ referees/ news/ sponsors/ rules/ applications/
  components/
    layout/                 ← Header, Footer, LogoBadge
    ui/                      ← Container, Button, VideoEmbed (YouTube-эмбед / ссылка на VK)
    forms/                   ← JoinForm (публичная форма "Заявить команду")
    admin/                   ← формы и поля админки (TeamForm, PlayerForm, fields.tsx…)
  lib/
    db.ts                    ← клиент Prisma
    content.ts                ← тексты по умолчанию (регламент, о лиге)
    video.ts                   ← разбор ссылок YouTube/VK для встраивания
    supabase/server.ts          ← клиент Supabase Auth для Server Components/Actions
    services/
      season.ts                  ← активный сезон
      standings.ts                ← автоматический расчёт турнирной таблицы
      stats.ts                     ← автоматический расчёт статистики игроков
    actions/                  ← Server Actions (создание/изменение данных)
      teams.ts players.ts referees.ts matches.ts news.ts sponsors.ts rules.ts applications.ts auth.ts
    slug.ts                   ← транслитерация кириллицы в URL-слаги
  middleware.ts               ← локаль (/ru,/kk) + защита /admin через Supabase Auth
```

## Что уже готово

- Next.js + TypeScript + Tailwind, адаптивная вёрстка, фирменные цвета `#0A1F44` / `#1E6FF8`.
- Логотип лиги в шапке, мобильном меню, на главной и как favicon/apple-icon.
- Двуязычность RU/KZ на уровне навигации, шапки и главной. Сами данные (названия команд, новости, регламент) администратор вводит один раз и они показываются одинаково в обеих языковых версиях — отдельного перевода каждой записи в базе нет (см. «Важные упрощения» ниже).
- Полная схема БД: сезоны, команды, игроки, судьи, матчи, составы, голы (с ассистентами и автоголами), жёлтые/красные карточки, новости, спонсоры, регламент, заявки команд.
- **Все публичные разделы подключены к базе и наполняются из админки**: Главная, Матчи (список + полная страница матча), Турнирная таблица, Команды (список + карточка), Игроки (список + карточка), Статистика/бомбардиры, Видео (галерея по матчам), Новости (список + статья), Регламент, О лиге (+ партнёры), Архив сезонов (список + таблица и бомбардиры конкретного сезона), Заявить команду.
- Страница матча: счёт, дата/место/судья, лучший игрок матча, составы двух команд, лента событий (голы по минутам с автором и ассистентом, жёлтые/красные карточки), embed видео с YouTube (по ссылке) или кнопка-ссылка на VK.
- Админ-панель на `/admin` (защищена Supabase Auth, один администратор): CRUD команд, игроков, судей, новостей, спонсоров, регламента, модерация заявок; матч со вложенным вводом составов, голов (автор + ассистент + автогол/пенальти), карточек, MVP и ссылок на видео. Счёт матча вводить не нужно — он считается автоматически по внесённым голам. Турнирная таблица и статистика игроков пересчитываются на лету при каждом открытии страницы — хранить их отдельно не нужно.

## Важные упрощения (сознательные решения, чтобы не затягивать запуск)

- **Изображения** (логотипы команд, фото игроков, обложки новостей) вводятся как ссылка на уже загруженную картинку (например, из облака или соцсети), а не загружаются файлом на сайт. Загрузку файлов через Supabase Storage можно добавить отдельным шагом.
- **Один активный сезон**: все админ-формы работают с сезоном, у которого `status = ACTIVE` (сейчас это 2026). Когда сезон 2026 завершится, в базе нужно будет создать сезон 2027 и переключить статус — интерфейс для этого внутри админки пока не сделан (делается точечно в базе данных или добавляется отдельным этапом).
- Регламент и текст «О лиге» — это один общий текст на весь сайт (регламент редактируется в админке, «О лиге» пока зашит в код) без раздельного перевода на казахский.
